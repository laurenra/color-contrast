Text Color Viewer

Try text color and background color combinations to see if they're readable. Hover on the ? hints for help.

Manual Colors Text color and background color are both set manually. Auto Black or White Text Text color is set to black or white automatically based on background color. Auto Complimentary Text Color Text color is set automatically to the inverted RGB value of the background color.
